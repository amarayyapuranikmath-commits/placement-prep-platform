# AI-Powered Placement Preparation Platform

An AI-powered placement preparation platform designed to help students prepare for technical interviews, coding assessments, aptitude tests, and placement interviews through a centralized web application.

## 🚀 Features

- 🔐 User Registration and Login
- 👤 Student Profile Management
- 📄 Resume Upload and ATS Analysis
- 💻 Coding Problem Practice
- ⚡ Online Code Execution
- 🤖 AI-Powered Technical Interviews
- 🧠 Aptitude Assessments
- 📊 Progress Tracking and Analytics
- 💡 AI-Based Performance Insights
- ⚙️ User Settings
- 🌙 Light and Dark Theme Support

## 🛠️ Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- React Router
- Axios
- Framer Motion
- Recharts

### Backend

- FastAPI
- Python
- MongoDB
- JWT Authentication
- Groq
- Judge0
- PyMuPDF
